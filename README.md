# Trial_WS_Simulator
A simulator for some climax combos and related card effects in trading card game Weiß Schwarz.

Python version: 3.11.4

Feel free to use it for analyse situation you're interested in, but don't use it for cheating or anything worse in real games.

This programme is coded and debugged with the help of AI.

Coding as a hobby. Non-Naive Engligh speaker. Can use Chinese and English.

All comments and feedbacks are welcomed.

## Introduction

一个能做到一些事情的ws模拟器。

支持常见的联动/伤害效果。

支持自定义卡牌，并能分析简单情况的残局决策。注意，未支持所有操作。支持的操作见决策树弹窗。
